# contributing

Please open an issue before broad UI or integration changes. Keep Live, Photodex, LenTalk and Guide compact; do not add manual progress bookkeeping or infer unknown game fields from browsing filters.

Use synthetic records in tests and screenshots. Never submit game archives/executables, console keysets, personal saves/photos, signing keys, tokens or raw device logs. A compatible installed game is separate from the app.

Follow [building](docs/BUILDING.md), run the source/publication checks and describe the actual validation scope. A local fixture or readable memory address does not prove a supported live field. Preserve existing records and distinguish saved progress from current-run context.

Original contributions are offered under the project's MIT license; third-party game content remains outside that license.
