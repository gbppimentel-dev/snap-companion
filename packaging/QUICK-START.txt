SNAP COMPANION

1. Install your own compatible New Pokémon Snap copy in the Eden Duo 1.4.0 package (dev.igawa6.edenduo) on AYN Thor and verify your backed-up/imported save loads normally. This APK does not migrate saves.
2. Install the APK over an existing release to preserve its app data.
3. Use a Duo-generated Snap shortcut in Cocoon and pair Snap Companion on the bottom screen. Set Snap's per-title No Companion option in Duo to Off.
4. Launch normally. The supported connection starts automatically; respond to Android permission prompts if presented.

The bundled read-only native reader supplies supported current course/level and rail/camera readings; no Duo mod is required. Some screen-only information still uses English OCR. Illustrated maps are partly aligned and reference pins are not live Pokemon actors. Unknown fields stay neutral. Battery shows current charge only. The app does not rank ungraded shots or guarantee 60 FPS. Other firmware/emulator packages are unverified. See compatibility.json and the GitHub documentation.
