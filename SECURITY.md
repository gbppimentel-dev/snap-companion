# security & privacy reports

Do not post credentials, signing keys, console keysets, user saves, raw screenshots or personal device logs in a public issue. Report a suspected vulnerability through the repository's private vulnerability-reporting option when available, or open a minimal issue requesting a private contact without disclosing exploit details or private data.

The app targets one firmware-dependent environment. Report the app/Android/Eden/game versions and a synthetic or redacted reproduction. Do not run untrusted modified firmware helpers. No public response-time commitment is made.
