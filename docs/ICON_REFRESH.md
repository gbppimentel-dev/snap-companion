# Companion icon refresh

Build 65 adds a rounded teal border, ivory inner keyline and a document badge integrated into the bottom-left corner. The original official game artwork remains underneath the overlay.

The release APK is an icon-only update of the previous installed build. The application ID and signing certificate are unchanged. App code, assets and native libraries are byte-identical; the version code and launcher icon resources changed. Install over the existing app to preserve data. No uninstall is required.

Game artwork and branding remain the property of their original rights holders and are outside this project's code license.
