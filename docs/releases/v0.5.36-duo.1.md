# v0.5.36-duo.1 — Eden Duo 1.4.0 support

This publishes the **exact code64 APK installed on Thor**, which is newer than
the previously published v0.5.35/code63 build. The installed binary was compared
by SHA-256 with the local signed APK on 2026-11-25; the revalidated build matches
it byte for byte. This publication does not reinstall or alter the device app.

## Changes since v0.5.35

- Targets **Eden Duo 1.4.0 (`dev.igawa6.edenduo`)** throughout supported
  save/photo, request, research, process visibility, focus/performance and
  native-reader paths. This is a Duo-targeted build, not stock/Duo auto-detection.
- Keeps the original `dev.gbppimentel.snapcompanion` package, signing certificate,
  private-data paths, current UI, maps and reference features. It remains a
  separate companion APK; a `.dsmod.zip` is not required.
- Requires a live game process before accepting a visible-window flag, preventing
  a dead emulator process from looking connected.
- Publishes the native reader's heartbeat with one atomic rename, avoiding a
  temporary missing watched path during backup-style replacement.
- Adds current Duo setup/migration notes, Cocoon shortcut guidance and the
  per-title **No Companion = Off** setting that keeps Duo's idle lower-screen
  page from covering the separate companion APK.
- Documents the checked optional **2× LSFG / SMAA** configuration. Frame
  generation is provided by Duo, not implemented or automatically enabled by
  this APK. The header's reported game FPS is distinct from presented-frame rate.

## Install/update and migration

Use your own compatible New Pokémon Snap 2.0.1 copy in Eden Duo 1.4.0 on the
supported AYN Thor firmware. Back up and import/verify existing stock-Eden
progress in the intended Duo profile before switching hosts; keep the originals.
This APK does not automatically migrate emulator saves or rebind arbitrary new
profiles. The owner's existing companion records were retained in the checked
migration; that is not a general automatic-migration guarantee.

Install `SnapCompanion-v0.5.36-duo.1.apk` over the existing companion without
uninstalling or clearing data. Use a Duo-generated Snap shortcut in Cocoon and
pair Snap Companion to the bottom screen. In Duo, set Snap's per-title
**No Companion** option to **Off**. See [Duo setup](../EDEN_DUO_SETUP.md) and
[general setup](../SETUP.md).

The emulator APK, LSFG DLL, shader cache, original game files, user saves/photos
and private backups are **not** distributed. Any required licensed LSFG DLL must
be supplied by the user through Duo's supported configuration. The prior
[v0.5.35 stock-Eden release](https://github.com/gbppimentel-dev/snap-companion/releases/tag/v0.5.35)
and its assets remain unchanged for users who have not migrated. Android version
restrictions apply to attempts to install older companion builds over newer ones.

## Validation and limits

On 2026-11-25, read-only device checks confirmed companion v0.5.36-duo.1/code64,
Duo 1.4.0 and the exact installed APK digest. Local checks pass: 200 Android
unit/Robolectric tests, 79 model/map tests, six offline diagnostic tests, native
reader checks, release lint with zero errors, publication boundary and original
identity/signer verification. All 1,554 compared code/native/asset entries match
the installed binary. The UI is unchanged from that installed build; this task
makes no new gameplay/performance acceptance claim.

The dated 2026-11-24 migration record includes paired cold Duo launches, loaded
saved progress/synchronization, and Park Day Lv.3 with a native illustrated-map
marker/trail and remaining-photo count. LSFG 2×/SMAA were checked in short samples:
presentation intervals near 16.6 ms were observed while reported game FPS was
around 30. These are short observations, not a sustained 60 FPS guarantee.

Map placement remains schematic/partial: portions of 30 illustrations / 121 of
123 known rails. Reference sightings are not live Pokémon actors. Some seasonal,
branch/event, restart/new-save, long-session and thermal cases remain unverified.
Forest/Camp whole-course totals stay neutral where continuation data is
incomplete. There is no live pose recognition or ungraded-photo ranking.
