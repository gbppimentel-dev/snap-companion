# v0.5.24 — first public release

The current Snap Companion app, packaged for GitHub with a small credits panel matching the author's other companions.

## included

- Live, Photodex, LenTalk and Guide with the established Snap-inspired artwork, fonts, paper frames and original category stars.
- Supported automatic saved-data/photo/request/research updates, offline reference search, course examples and Photo Selection benchmarks.
- Capture generation/freshness safeguards, asynchronous OCR recovery, bounded retries, quiet-scene image import and lower-overhead controller-display timers.
- Credits opened from the GitHub-mark button beside the header clock.
- Public source, setup/compatibility/privacy/build docs, issue templates and release checksums.

## known limits

Course/selected-level recognition remains dependent on supported English labels. Route/visual/audio recognition, wider saved unlock/ownership fields, full hardware-flow acceptance and sustained performance/gyro/black-photo recovery remain limited or unverified. See [compatibility](../COMPATIBILITY.md). The release does not promise complete automation or universal60FPS.
