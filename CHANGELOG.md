# release history

## 0.5.35

Publishes the APK development since v0.5.24, with the original package/signer/data.

- Bundled read-only native game reader for supported course, variant, selected level, rail position and render-camera fields; no separate Duo mod required.
- Thirty expandable illustrated course maps, 1,403 reference sightings, measured NEO-ONE trails, named section progress and branch/rejoin-aware current-path totals where supported.
- Default Follow, retained zoom, sharper fixed-size pins, exclusive map filters, guarded camera cone and bounded event/handoff recovery.
- Snap-asset header/tabs/controls, compact Photodex and filters, redesigned photo books, four-photo albums, illustrated LenTalk readers and island-based Guide.
- Course-specific star-photo setup/timing methods, optional reviewed LenTalk details and clear Option/OR grouping for 258 existing multi-hint categories.
- Newest saved snapshots import first; fallback cutouts, image placement and photo-reader headers refined.
- Removed automatic Photo Selection comparison page and grading helper; Live stays on its main dashboard.
- Header shows a quiet battery icon and charge percentage only; removed the health/Good label.
- Updated setup, compatibility, privacy, build/release documentation and synthetic screenshots.

Known limits: map placement remains partial; authored sightings are not live actors; latest event/fork fixes have local checks but no completed live split-path run. See the v0.5.35 release notes.

## 0.5.24

- First public GitHub package of Snap Companion.
- Added the compact creator/contributor credits reader.
- Added public setup, compatibility, privacy, build and third-party notices.
- Retained the0.5.23 processing/recovery work and current reference/collection interface.

Earlier0.5.x builds were private development iterations. The public compatibility documentation records the retained limitations without importing private development logs or personal device records.
